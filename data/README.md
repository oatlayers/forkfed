# Generated data

This directory is the pipeline's working directory. Except for this README and `feedback_source.txt`, every file here is generated by the scripts and is ignored by Git.

`feedback_source.txt` is the community corrections text used to verify that the feedback triage ledger covers every reported block. It is committed on purpose.

Do not edit generated JSON/CSV files by hand. Change the curated sources in `scripts/lib/` and rerun the pipeline. The main artifacts and their roles are listed in [Building from source](../docs/BUILDING.md#generated-data).

`qa.json` is rewritten by `scripts/validate_deck.py` and records the current package hash, size, and validation matrix.
