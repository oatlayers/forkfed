# Source deck

Put the source APKG here as:

```text
Spoonfed_Chinese_Forkfed.apkg
```

It is not committed because it is about 121 MB, over GitHub's 100 MiB per-file limit.

Download the base Spoonfed Chinese deck from [AnkiWeb 772959041](https://ankiweb.net/shared/info/772959041) and save it under that name. The pipeline expects the source deck to contain 7,335 notes, four fields (`English`, `Pinyin`, `Hanzi`, `Audio`), and 7,316 media files.

See [Building from source](../docs/BUILDING.md) for the full pipeline. Everything in this directory except this README is ignored by Git.
